# GameButton (робоча назва)

Android-додаток (Kotlin) з плаваючою **кнопкою взаємодії** поверх будь-якої гри.
Кнопка читає екран (OCR), розуміє що саме потрібно грі (код, пароль, тап) і виконує це за гравця.

## Флоу
1. Дозвіл на плаваючі вікна (overlay)
2. Головне меню: вибір стилю кнопки
3. `Select Game` → `Start Game`
4. Гра відкривається вже з кнопкою

## Структура модулів
| Пакет | Призначення |
|-------|-------------|
| `overlay/` | плаваюча кнопка (готово: показ + перетягування) |
| `capture/` | захоплення екрана (MediaProjection) — готово |
| `ocr/` | розпізнавання тексту/цифр (ML Kit, латиниця) — готово |
| `input/` | тапи (AccessibilityService) + правила вибору дії — готово |
| `ui/` | головне меню, вибір стилю і гри |
| `data/` | налаштування, обрана гра/стиль |

## Збірка
Android Studio / AndroidIDE: відкрити папку, Sync, Run.
CLI: `gradle assembleDebug` (Gradle 8.7+, JDK 17).

## Увага
Використовуй на свій ризик: в онлайн-іграх з античітом можливі блокування акаунта.

## Як працює кнопка
- Раз на секунду скан екрана (OCR) → шукає цифровий код+клавіатуру або підказки "Press/Interact/Open…".
- Кнопка світиться, коли щось знайдено. Тап — натиснути. Довге утримання — авто-режим (зелена).

## AI-режим (опційно)
Отримай безкоштовний ключ у Google AI Studio, встав у додатку, увімкни «AI-режим».
Gemini знаходить усі натискні елементи (кнопки, клавіші, підказки), без читання кодів; кожен тап по кнопці тисне наступний із них. Викликається лише коли OCR нічого не знайшов (не частіше 1 разу на 15 с в авто-режимі).
Скріншоти йдуть до Google — не вмикай на екранах з особистими даними.
